# AI Radio

Локальное интернет-радио на FastAPI. Выберите Lo-fi, джаз, эмбиент, хаус или рок. Сервис генерирует инструментальные фрагменты примерно по 20 секунд, а плеер запрашивает следующий во время воспроизведения. Радио продолжает генерировать музыку до остановки или закрытия страницы. Если модель работает медленнее воспроизведения, между треками будет пауза.

Веса [MusicGen Small от Meta](https://huggingface.co/facebook/musicgen-small) доступны бесплатно по лицензии CC BY-NC 4.0 для некоммерческого использования. API-ключ не нужен. При первом запросе потребуется интернет для скачивания весов с Hugging Face (около 2,36 ГБ). PyTorch автоматически использует CUDA при наличии совместимой сборки и видеокарты NVIDIA. В остальных случаях модель работает на CPU, где ожидание может быть дольше.

## Запуск в Docker

Нужны Docker с Linux-контейнерами и Docker Compose v2. Из корня проекта:

```powershell
docker compose up --build --wait
```

Откройте [плеер](http://127.0.0.1:8000/) или [документацию API](http://127.0.0.1:8000/docs). Порт публикуется только на локальном интерфейсе. Если порт 8000 занят, перед запуском задайте в PowerShell `$env:RADIO_PORT = '8080'` и откройте плеер на новом порту.

Контейнер использует CPU. Веса скачиваются при запросе первого трека и сохраняются в томе `model-cache` между запусками, пересборками и пересозданиями контейнера. Для первой загрузки нужны интернет и место для весов вдобавок к месту для образа. Маршрут `GET /healthz` проверяет доступность API, в том числе во время генерации. Загрузка модели начинается после выбора жанра и запуска эфира.

```powershell
docker compose config --quiet
docker compose ps
docker compose logs -f radio
docker compose down
```

`docker compose down` сохраняет том с моделью. Нажатие Ctrl+C при просмотре логов завершает просмотр.

## Запуск на Windows без Docker

Нужен Python 3.12. Если Windows Launcher не находит установленный Python, замените `py -3.12` в первой команде на `&` и полный путь к `python.exe` в кавычках. Выполните в PowerShell из корня проекта:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-music.txt
.\.venv\Scripts\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

Откройте [плеер](http://127.0.0.1:8000/) или [документацию API](http://127.0.0.1:8000/docs). Проект запускается из исходников и не требует отдельной сборки. Для локального запуска используйте один процесс Uvicorn, чтобы хранить одну копию модели в памяти.

- `GET /api/genres` возвращает идентификаторы и названия жанров.
- `POST /api/genres/{genre}/tracks` запускает генерацию и возвращает один WAV-фрагмент. Пока модель занята, сервер отвечает `503` с заголовком `Retry-After`. Плеер повторяет запрос по истечении этого интервала.

## Тесты

Из виртуального окружения, созданного по инструкции выше:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-test.txt
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

Тесты подменяют генератор коротким WAV-фрагментом в памяти. Для них не нужны веса, PyTorch или GPU.

## Структура

- `Dockerfile` и `compose.yaml` — сборка CPU-образа и запуск с постоянным кешем весов.

- `app/main.py` — точка входа FastAPI и маршруты.
- `app/music.py` — жанры, промпты и локальная генерация MusicGen.
- `app/player.html` — плеер со встроенными стилями и JavaScript.
- `tests/test_radio.py` — тесты HTTP API. Аудиофайлы и веса в проекте не хранятся.
